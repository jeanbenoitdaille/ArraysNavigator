# Arrays Navigator

Exercice JavaScript sur plusieurs opérations courantes appliquées à un tableau de chaînes.

## Objectif pédagogique

Manipuler :

- `Array.every()` ;
- `Array.sort()` ;
- `Array.filter()` ;
- `Array.join()` ;
- une fonction de prédicat basée sur la longueur d’une chaîne.

## Fonctionnement

Le script utilise une liste de navigateurs web pour :

1. vérifier si tous les noms dépassent une certaine longueur ;
2. trier le tableau ;
3. filtrer les éléments selon leur longueur ;
4. recomposer une chaîne avec `join()`.

## Point pédagogique

Le commentaire historique parle d’au moins 5 caractères alors que la fonction teste strictement `element.length > 5`.

## Fichier principal

`index.js`

## Exécution

Exécuter le fichier dans un environnement JavaScript compatible avec `console.log()`.
